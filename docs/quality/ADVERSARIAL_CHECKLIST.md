## RSS 設定検証（2026-11-07）

目的: 設定の型誤りによる汎用例外と、文字列 `"false"` による意図しない絞り込み解除を防ぐ。
受け入れ条件: 不正な設定は項目付きエラーで終了コード1となり、取得・通知・出力更新を開始しない。
現行 `feeds.yml` と正しい真偽値・HTTP(S) URL は受け入れ、入力を変更しない。

| 観点 | 攻撃した内容 | 結果・テスト |
| --- | --- | --- |
| 悪意ある入力 | 空YAML、配列、数値、欠損文字列、不正URL・制御文字、型違いキーワード | `test_rss_config.py` で検証エラーとして拒否 |
| テストの弱体化 | 既存テスト・CI構成を変更しない | 新規回帰テストを追加。削除・skip追加・期待値緩和なし |
| 権限・秘密値 | 不正値をエラーへ転記しない | `test_invalid_values_are_not_echoed`。権限・認証変更なし |
| 依存関係 | 標準ライブラリのURL解析だけを使用 | 依存・ロックファイル変更なし |
| 失敗・リトライ | 設定異常時の処理順 | `test_main_stops_before_collection_notification_and_output`。取得・通知の開始なし |
| 冪等性 | 設定検証で入力・出力を変更しない | 入力の非変更と既存出力の保持を検証。配信処理変更なし |
| ログの機密情報 | URL・言語の不正値を含めない | 入力値を含まない項目付きエラーを検証 |
| 後方互換 | 現行設定、既定値、明示したtrue/false、HTTP/HTTPS | 現行設定と有効設定の回帰テスト |

DoD: 回帰テスト・static・unit・api・変更弱体化検査を実行し、結果を保存する。
既存の型検査とE2Eのskipは合格扱いせず、公開・マージ・実通知の確認とは分離する。
